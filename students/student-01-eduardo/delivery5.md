## Prototype Description
O protótipo consiste em um aplicativo mobile chamado RecicloFácil, desenvolvido para auxiliar usuários a localizar pontos de coleta seletiva próximos de sua localização.

O sistema possui integração com GPS, mapas interativos, cadastro de ecopontos, upload de imagens e sistema de avaliações.

---

## Navigation Flow
- Tela inicial do aplicativo
- Permissão de localização
- Visualização do mapa interativo
- Listagem de pontos de coleta
- Visualização de detalhes do ponto
- Cadastro de novo ecoponto
- Avaliação dos pontos cadastrados

## System Explanation
O sistema utiliza o GPS do dispositivo para identificar a localização do usuário e exibir pontos de coleta seletiva próximos através de um mapa interativo.

Os usuários podem cadastrar novos ecopontos, adicionar fotos, visualizar informações detalhadas e realizar avaliações. Todas as informações são armazenadas em banco de dados online utilizando Supabase.

---

## Final Considerations
O desenvolvimento do RecicloFácil permitiu aplicar conceitos de sistemas multimídia, computação móvel e integração com serviços externos.

O projeto demonstrou a importância do uso de tecnologias interativas para conscientização ambiental e mostrou como recursos multimídia podem melhorar a experiência do usuário.

Como melhorias futuras, o sistema poderá incluir vídeos educativos, notificações inteligentes e inteligência artificial para recomendação de pontos de reciclagem.
