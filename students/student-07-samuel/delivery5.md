## Navigation flow

When the user accesses the platform, the system automatically analyzes the computer's hardware components and generates an overall performance score. The main dashboard presents a summary of the analysis, including individual ratings for each component and a global system classification.
Users can navigate through different sections using the tab menu at the top of the page. The System Components tab displays detailed information about the CPU, GPU, RAM, storage devices, motherboard, and power supply. The Compatibility Matrix section allows users to verify whether their components work efficiently together. In the Upgrade Recommendations tab, the system suggests potential hardware improvements based on current performance and compatibility data. Finally, the Customization section enables users to explore alternative configurations and evaluate how changes may affect the overall system score.

## System explanation

The system is designed to provide a comprehensive evaluation of a computer’s hardware setup. It collects technical specifications from key components and analyzes their performance, compatibility, and market positioning. Each component receives an individual score based on factors such as processing power, memory capacity, clock speed, efficiency, and overall capability.
The results are displayed through an intuitive dashboard where users can quickly identify strengths and weaknesses within their configuration. In addition to performance analysis, the platform helps users make informed decisions by highlighting compatibility issues and recommending upgrades that could improve the system’s overall rating. This makes the tool useful for gamers, professionals, and general users who want to assess their current hardware and plan future improvements with confidence.
